# Brag Plan: Autonomous AI Agency (feature tour, v2)

## What is this app?
A self-hosted platform that turns one website URL into a working AI operations team — it scans your stack, audits it, provisions the specialist agents your business needs, and runs them 24×7 on your own hardware with human approval gates on anything that ships.

## The angle
Show the product, not vanity metrics. A ~44s feature tour that walks the real flow and capabilities end to end: paste a URL → stack scan → CTO-grade audit → the specialist fleet → the plan/execute/verify loop → the approval gate → 24×7 schedules → multi-provider failover on your own infra. Every scene is a real capability pulled from the README and docs/platform-guide.md.

## Tone
- Preset: app-store / polished hybrid
- Creative direction: clean feature cards, smooth slides, one accent per scene, premium dark UI
- Interpretation: energetic but controlled; readable holds; the product's own language, no generic SaaS speak

## Format: landscape — 1920x1080
## Duration: ~44s (9 scenes) — intentionally longer than the /brag 15-25s default, per an explicit user request for a longer video

## Storyboard (9 scenes)
1. Hook (0-3.5s) — dark terminal, "paste your website URL" types out. Kicker: "one URL · a whole AI team."
2. Stack scan (3.5-8.5s) — detected-system chips appear: Shopify · Stripe · GitHub · Analytics · Intercom · Salesforce. "Playwright + HTTP fingerprinting → AI-generated onboarding questions."
3. CTO-grade audit (8.5-13.5s) — health-score dial counts 0→74, six pillars (Technical · Content · Security · Social · GEO · AIO). "100+ checks · findings priced as revenue-at-risk."
4. The fleet (13.5-19.5s) — "35 specialist families — auto-provisioned, CEO-coordinated." Chips: Engineering · Security · DevOps · SEO · Content · Support · E-commerce · Data · Research.
5. The loop (19.5-25.0s) — Plan → Execute → Verify, with "failures become lessons the planner reuses." Verifier must pass before apply.
6. HITL gate (25.0-30.5s) — an awaiting-approval task card (Draft PR #142) with Approve · Deny · Redirect. "Auto-approve the trivial. Gate the production."
7. 24×7 (30.5-36.0s) — schedule rows: Health scan · Security & CVE audit · Trend watch · Doc-sync · Company graph sync, with cadences. "Agents find it, fix it, then brief you."
8. Self-hosted routing (36.0-41.0s) — provider chain NVIDIA NIM → Cerebras → Groq → Ollama with automatic failover. "OpenAI-compatible proxy · switch models with no redeploy."
9. Outro (41.0-44.0s) — wordmark, "Self-hosted · MIT · One URL → a working AI team," URL.
